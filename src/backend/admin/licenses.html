授权码管理（SQLite · 明文积分码）

功能：管理积分 SQLite 中的明文授权码：批量生成、分页列表、禁用与删除（受规则限制）。JWT 会员列表在 Auth 服务 「License 授权」中维护。
管理 API 需请求头 x-admin-token；未单独配置 ADMIN_TOKEN 时开发默认与 Auth 一致为 flowid-admin-dev。
路径：请使用含 /pts 的地址（如 http://127.0.0.1:3721/pts/admin/licenses）。口令保存在浏览器 localStorage（flowid.pts.admin.token.v1），勿在公共电脑使用本页。
测试清库：有积分流水时默认不能删授权码。勾选「删码时清除积分流水」后删除，会在非 production（常见本地默认）或已设置 FLOWID_ALLOW_LICENSE_PURGE=1 时先删流水与相关死信再删码。正式环境若 NODE_ENV=production，需显式设置 FLOWID_ALLOW_LICENSE_PURGE=1 才允许该选项。
