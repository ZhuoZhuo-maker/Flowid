批量补偿（批量退款）

说明

  • 接口：POST /api/admin/batch-refund（请求路径前缀为 /pts）
  • 功能：对 points_log 中 type=refund 且在时间范围内的记录按笔数等额补偿入账（幂等 dedupe）。
  • 预扣（reserve）：处理 points_confirm_failures 中 pending 时，若关联流水仍为 reserve，将先释放预扣再充值；若已为 consume 则仅关单。
  • 鉴权：请求头需携带 x-admin-token（与服务器 ADMIN_TOKEN 一致）。

管理员认证

未配置 ADMIN_TOKEN 时，开发环境默认口令一般为 flowid-admin-dev（以服务端为准）。输入后会保存到本机浏览器，便于下次使用。

补偿参数

支持 YYYY-MM-DDTHH:MM:SS 或 YYYY-MM-DD HH:MM:SS；可与下方快捷选择联动。

时区：按本地时区解析与展示；提交时 T 与空格等价。

快捷填入（datetime-local，写入上方文本框）
处理选项

两项可同时勾选；若全部取消，将无法执行。

接口返回 JSON
