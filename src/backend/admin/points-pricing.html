积分单价规则

规则说明

rule_key 用于匹配预扣单价，保存后立即作用于 /pts/api/points/reserve 与 /pts/api/points/quote（与画布 / Agent 侧 slug 一致）。
  • 扣费范围：仅当命中 workflow: 或 model: 规则时扣积分；无匹配规则则预扣为 0。本地 Comfy 预扣恒为 0（元数据 pointsBillingKind=local_workflow，由画布写入）。不再读取 base: 与内置数字兜底。
  • 遗留 base:*：在「全部」列表里若仍可见，可逐条删除；服务端已不再用其计价。
  • 云端 Comfy 工作流：workflow:{slug}，slug 为画布上该工作流显示名规范化（小写、空格→下划线），须与 Auth「云端 ComfyUI 工作流」里的名称一字不差（否则命中不到规则、扣 0）。
  • 云端模型：model:{slug}，与 Auth「云端模型」配置中的模型名一致。
后端接口说明：列表为 GET /pts/api/admin/points-pricing；新增与更新统一使用 PUT /pts/api/admin/points-pricing（Upsert），删除为 DELETE 且 JSON body 带 ruleKey（与现有实现一致，非文档中的 POST）。

从 Auth 云端目录快速绑定

从本机 Auth 根路径拉取（无需积分口令）：GET /cloud-models、GET /cloud-workflows。选择后点击按钮自动填入 rule_key 与描述，再点「保存」即可。
