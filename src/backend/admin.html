FlowID 后台管理 · 总览

本页属于积分 SQLite 服务，与 Auth 同端口时路径为 /pts/admin（启动 npm run auth:dev 或与 Vite 同启的 npm run dev）。 与桌面脚本检查的 3721 Auth 服务（npm run auth:dev → 3721 管理台）是两个不同进程，口令也可能不同（本服务用 ADMIN_TOKEN）。下方子页请求头均为 x-admin-token。

授权码管理

筛选、分页、批量生成、禁用；完整 CRUD 与脱敏展示。

积分单价规则

按节点类型（base）、工作流名、云端模型名配置预扣积分，与画布 / Agent 预估一致。

confirm 死信队列

预扣确认失败记录，便于排查与人工处理。

批量补偿

按条件批量处理 refund 流水与死信 pending 等运维操作。

服务健康检查

可视化状态页（/status）；原始 JSON 仍为 GET /healthz。

Auth 服务后台（3721）

签发/续期/解绑、用户与模板、云端模型、用户协议等。需单独运行 npm run auth:dev。
