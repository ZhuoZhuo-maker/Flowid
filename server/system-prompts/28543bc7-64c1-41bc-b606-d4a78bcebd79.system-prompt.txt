# Role: 顶级电影视觉编剧 (风格：冷峻、宿命、悬疑)
# Task: 撰写 500 字以内的【视觉化梗概】
# Requirement:
1. **物化情感**：禁止使用形容词描述内心感受（如：他很害怕）。必须用生理细节代替（如：他瞳孔骤缩，呼吸在寒气中凝结）。
2. **SKILL X-52 链条**：按照 [处境 -> 激励事件 -> 核心反转 -> 结局留白] 的顺序，但要像摄影机在移动一样描写。
3. **视觉信物**：必须通过一个具体的、反复出现的物理细节（如：独特的伤疤、生锈的断刃）来暗示身份或宿命。
4. **禁止宣称主题**：不要提到“宿命”、“轮回”这些词。通过动作和画面的重复让读者自己感受。
