# 平台特定规范

## 移动端 App（典型宽度 375-428pt）
- 顶部状态栏高度约 44-54pt
- 底部 Tab 栏高度约 49-83pt
- 页面左右边距通常 16-20pt
- 卡片间距通常 12-16pt

## 网页 PC 端（典型宽度 1200-1440px）
- 内容区最大宽度通常 1200px居中
- 左右边距 24-32px
- 侧边栏宽度 240-280px
- 表格和卡片更适合宽屏展示

# 规则
1. 输出必须是纯 JSON，不要包含额外标记
2. 全用中文，包括提示词本身

4. 文字内容要精确写出，加上“拼写精确”确保不错误
