请求头与鉴权

  • x-license-code + x-machine-id：客户端授权相关（用于受保护接口）。
  • x-admin-token：管理员接口（/admin/*）。NODE_ENV=production 时强制校验。
Pro 分组可见性：License 有效且 entitlements.proTemplates 为 true。

公共基础接口

  • GET /healthz · 可视化状态 /status（/healthz-ui 同页）
  • POST /proxy/openai（白名单目标：dashscope.aliyuncs.com）

License 授权接口

  • POST /license/activate
  • POST /license/verify

预设模板（free / pro）

  • GET /templates/groups
  • GET /templates/:id
  • GET /templates/:id/workflow 与 GET /templates/:id/workflow.json（工程 JSON，客户端「调用预设」）
  • POST /tasks/submit（需要 license headers）
  • GET /tasks/:taskId/status（需要 license headers）

系统提示词（free / pro）

  • GET /system-prompts/groups
  • GET /system-prompts/:id（含 SHA256 + HMAC 防篡改校验）
